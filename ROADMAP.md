# Roadmap

This roadmap keeps development concrete while preserving the project's review-only safety boundary.

## Now

- Strengthen deterministic complete-basket comparison with fictional fixtures.
- Expand substitution tests for protected attributes, package sizes, and dietary constraints.
- Improve contribution templates and newcomer documentation.

## Next

- Add adapter examples for retailer-neutral offer ingestion.
- Add freshness scoring for prices, coupons, fees, and availability.
- Add richer delivery-coverage and incomplete-basket explanations.

## Later

- Publish an interoperability guide for additional agent runtimes.
- Add optional local persistence adapters with explicit retention controls.
- Explore privacy-preserving evaluation against larger synthetic baskets.

## Non-goals

- Autonomous checkout or order placement.
- Storing credentials, payment information, or exact delivery addresses in repository state.
- Presenting unverified discounts as guaranteed savings.

Open an issue before beginning a large roadmap item so scope and safety assumptions can be reviewed first.
